# 场景指南

只在多人合盘或用户明确要求场景建议时加载。

## 场景选择

| `scenario` | 关注点 | 避免 |
|---|---|---|
| 情侣/伴侣 | 冲突修复、需求表达、共同节奏 | 判定“正缘”、承诺婚期或分手结论 |
| 亲子 | 年龄适配、情绪回应、边界与自主性 | 给儿童贴固定人格标签 |
| 职场搭档 | 信息同步、决策权、交接与互补 | 用命理决定录用、晋升或薪酬 |
| 团队协作 | 角色覆盖、盲区、会议与冲突机制 | 按分数机械分工 |
| 管理者与下属 | 目标清晰度、反馈方式、授权边界 | 监控、操纵或歧视性建议 |
| 朋友 | 互动节奏、支持方式、边界 | 用合盘否定真实友谊 |

## 多人规则

- 2 人默认“朋友”；3 人以上默认“团队协作”。默认值只是技术假设，交付时说清楚。
- 生肖、星座、日主等两两关系采用“人对均值”，不能随人数累加。
- 展示团队整体分布后，再指出最多 2–3 个值得现实验证的关系对；不要逐对写成长篇断语。
- `composite_scores.total` 是 100 分制；全员没有可用姓名时姓名项为 0，`max_possible` 降为 95。

## 建议结构

每项场景建议包含：

1. 排盘中观察到的结构。
2. 这可能对应的互动假设。
3. 一个低风险、可执行的现实实验。
4. 一周或一个项目周期后的复盘问题。

例如：“两人的沟通节奏可能不同”之后，给出“重要事项先书面再口头确认”，而不是断言“你们天生无法沟通”。
