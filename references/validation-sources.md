# 第三方交叉验证

第三方交叉验证用于发现实现错误和锁定回归，不证明命理体系具有科学预测效度。

## 固定引擎

| 本地模块 | 独立对照 | 固定版本 | 验证内容 |
|---|---|---|---|
| 四柱 | `lunar-python` | 1.4.8 | 年、月、日、时柱固定样本 |
| 太阳/月亮/上升 | Swiss Ephemeris Python binding `pysweph` | 2.10.3.6 | UT 黄经与上升点 |
| 紫微斗数 | `iztro` | 2.5.1 | 四柱、命宫、身宫、五行局、14 主星与 12 辅星落宫 |

Python 版本锁在 `requirements-dev.txt`，Node 版本锁在 `package-lock.json`。

## 容差

- 太阳黄经：绝对环形误差 `< 0.05°`。
- 月亮黄经：绝对环形误差 `< 0.15°`。
- 上升点黄经：绝对环形误差 `< 0.05°`。
- 四柱与紫微离散字段：必须完全一致。

本地月亮算法是 Meeus 主要项近似；容差描述的是与 Swiss Ephemeris 的实现一致性范围，不是观测误差声明。

## v8.3 验证快照（2026-08-31）

- `lunar-python`：8 组跨年代样本的 32 个四柱字段全部一致。
- Swiss Ephemeris：4 组中国/境外样本中，太阳最大误差 `0.0083°`、月亮 `0.0377°`、上升点 `0.0058°`，均低于测试容差。
- `iztro`：4 张命盘的四柱、命宫、身宫、五行局全部一致；14 主星 + 12 辅星共 104 个落宫字段全部一致。

该快照由 `tests/test_third_party.py` 现场重算，不是手工复制的期望 JSON。

## 运行

```bash
pip install -r requirements-dev.txt
npm ci
python tests/test_third_party.py
```

测试同时覆盖两个已知回归：

- 境外出生时间必须用当地时区换算 UT，不能硬编码 UTC+8。
- 紫微辅星必须包含天马，并按出生年支分组落宫。

晚子时的日柱存在流派差异，固定样本避开该分歧；对比外部工具时应单独声明本项目采用“不换日柱”。
